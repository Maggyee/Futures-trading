# 已发布的回测记录

本次发布项目源码和截至2026-10-08的研究结果。当前保留方案仍为原7笔研究版，最新两项改动均未通过预先固定的保留标准。

## 最新顺序实验

目录为`research_outputs/structure_followup_2026-10-07/`。原始结果文件按原字节保存，包括：

- 三组方案在三个开发窗口的9个有效回放：配置、运行清单、交易／信号／委托／事件／资金记录、源码快照及独立审计。
- 最终`assessment.json`、`research_candidate.json`及`completion_verification.json`。
- `trade_review/`下的逐笔交互报告、CSV、桌面／手机截图和浏览器核验记录。
- 两次技术失败尝试的已有元数据及失败说明；未完成的临时流文件继续留在本地。

最新报告中各方案各有7笔成交，合计21笔版本记录，对应7个相同的入场机会，不是21个独立交易样本。新增确认通道实际成交为0，另有3处确认后被取消或拦截的案例。

当前结果已经扣除手续费和双边不利滑点。52个交易日为7月、8月和9月14—23日，均为已经查看的开发窗口。原策略最佳一笔占总净收益95.48%，去掉最佳两笔后为亏损1,805.95元。结构止损的回撤降低，但减仓及盈利保护启动价变化使净收益下降至1,115.09元。
